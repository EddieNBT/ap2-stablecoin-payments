Contributing
We welcome contributions to this AP2 stablecoin payments exploration!
How to Contribute
Fork this repository
Create a branch for your changes
Submit a Pull Request with a clear description
Areas We Need Help With
Additional social entertainment use case documentation
Stablecoin payment method specification refinements
Sample code for other AP2 scenarios (tipping, subscriptions)
Multi-chain settlement optimization research
Integration testing with AP2 SDK (when published)
Code Style
Python: Follow PEP 8
Documentation: Markdown, clear headings, tables for structured data
Commit messages: Present tense, concise
